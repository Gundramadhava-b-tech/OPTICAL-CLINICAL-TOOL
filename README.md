## 🧪 CI/CD Testing System
This project features a comprehensive CI/CD system implemented with **GitHub Actions**, providing real-time validation of every commit.

### **Master Pipeline Structure**
- **🧪 Unit Tests**: Full coverage for API, Flutter, and AI modules.
- **✅ Validation Tests**: Business logic and data isolation verification.
- **🌐 Selenium Web Tests**: E2E browser automation for the Web dashboard.
- **📱 Appium Android Tests**: Automated UI testing on mobile devices.
- **⚡ Load Testing**: Performance benchmarking for API endpoints.
- **🚀 Deployment Status**: Build integrity for Web and Android APK.

### **Executive reporting**
Every pipeline run generates an **Executive Master Test Summary** available via GitHub Actions and deployed to GitHub Pages.
