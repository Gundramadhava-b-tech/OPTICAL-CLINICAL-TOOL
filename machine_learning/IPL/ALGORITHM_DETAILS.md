# IPL: Inner Plexiform Layer

## Anatomical Significance
The **Inner Plexiform Layer (IPL)** is a synaptic layer containing the connections between bipolar cells, amacrine cells, and retinal ganglion cells.

## AI Segmentation Logic
- **Identification**: A moderately hyper-reflective layer located between the GCL and the INL.
- **Features**: Often shows a granular texture in high-resolution OCT.
- **Topology**: $GCL \prec IPL \prec INL$.
