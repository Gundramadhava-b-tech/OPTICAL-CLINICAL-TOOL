# Machine Learning & Retinal Algorithm Repository

This directory contains isolated implementations, training scripts, and documentation for the various scientific algorithms used in RetinaSeg AI.

## 👁️ Retinal Layer Sub-Modules
- **ILM**: Internal Limiting Membrane algorithms.
- **RNFL**: Retinal Nerve Fiber Layer analysis.
- **GCL**: Ganglion Cell Layer segmentation logic.
- **IPL**: Inner Plexiform Layer processing.
- **INL**: Inner Nuclear Layer identification.
- **OPL**: Outer Plexiform Layer logic.
- **ONL**: Outer Nuclear Layer analysis.
- **RPE**: Retinal Pigment Epithelium complex algorithms.

## 🧪 Scientific Processing Algorithms
- **U_NET_ARCHITECTURE**: Multi-depth residual neural network definitions.
- **CLAHE_ENHANCEMENT**: Local contrast adaptive histogram equalization implementations.
- **BILATERAL_FILTERING**: Edge-preserving speckle noise reduction scripts.
- **GRAYSCALE_CONVERSION**: Standardized luminance conversion matrices.
- **DYNAMIC_RANGE_NORMALIZATION**: Min-Max scaling and bit-depth standardization.
- **SUZUKI_ABE_CONTOURS**: Vector boundary extraction algorithms.
- **THICKNESS_CALIBRATION**: Axial resolution to micrometer conversion logic.
